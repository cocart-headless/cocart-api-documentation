## What is CoCart?

You've chosen WooCommerce for your store. Now you want a modern frontend — React, Next.js, Astro, Vue — without being locked into WordPress themes. That's exactly what CoCart is built for.

CoCart gives WooCommerce a proper frontend REST API: cookie-less session management built for stateless frontends, authentication that makes sense, and CORS support built in. Build the storefront you want with any framework. Scale up when you're ready.

## Core features

<AccordionGroup>
    <Accordion title="Cookie-less session management" icon="cookie-bite">
        Database-stored cart sessions built for concurrent requests and stateless frontends. No cookies, no session conflicts — works for both guest and authenticated customers from day one.
    </Accordion>

    <Accordion title="Customer authentication" icon="key">
        No admin API keys required. Customers authenticate with their own credentials:

        - Email and password
        - Username and password
        - Phone number and password

        JWT authentication is available via add-on.
    </Accordion>

    <Accordion title="CORS support built in" icon="globe">
        First-party CORS handling so your decoupled frontend connects without configuration hell. Enable it in one click with the [free CORS add-on](https://wordpress.org/plugins/cocart-cors/) or control it via filter.
    </Accordion>

    <Accordion title="Essential cart operations" icon="cart-shopping">
        Add, update, and remove items via simple POST/PUT/DELETE requests. Name Your Price support is built in for donation-based and flexible pricing. Bulk cart requests let you combine multiple operations into a single API call.
    </Accordion>

    <Accordion title="Product search" icon="magnifying-glass">
        Query products by name, SKU, or ID — authenticated or not — with flexible filtering. Return different results based on role type (membership, wholesale, and more).
    </Accordion>

    <Accordion title="Real-time cart validation" icon="check">
        Stock, coupons, totals, and fees are validated on every request. Responses are always accurate — no separate verification calls needed.
    </Accordion>

    <Accordion title="180+ filters" icon="filter">
        Customize every response, add fields, or remove data you don't need — without writing new routes.
    </Accordion>

    <Accordion title="Broad plugin compatibility" icon="puzzle-piece">
        Built on WooCommerce's Data Stores API and mirrors most WooCommerce hooks. Most extensions — subscriptions, memberships, dynamic pricing — work out of the box.
    </Accordion>
</AccordionGroup>

## SDKs and tools

### TypeScript SDK

The official TypeScript SDK ships with zero dependencies, typed responses, and framework adapters for Next.js, Astro, Nuxt, SvelteKit, Remix, and more.

```bash
npm install @cocartheadless/sdk
```

```typescript
import { CoCart } from '@cocartheadless/sdk';

const client = new CoCart('https://your-store.com');
const cart = await client.cart().get();
```

## Why CoCart instead of WooCommerce's Store API?

WooCommerce's Store API can be used headless, but it was designed for the Gutenberg block editor ecosystem. Its session model relies on nonces passed via response headers — suited for anonymous single-session shoppers, but tied to WordPress's nonce lifecycle and less straightforward to persist across sessions or devices.

CoCart is purpose-built for headless from day one: cart sessions identified by a persistent key (no nonces, no cookies), a single unified endpoint set for both product and cart data, and customer authentication that supports any shop requirement.
