                <Accordion title="Do I need to modify WooCommerce to use CoCart?">
                    No. CoCart is a standalone WordPress plugin that provides its own REST API for WooCommerce. Install it, activate it, and your existing WooCommerce setup works as-is. No core modifications, no theme changes.
                </Accordion>

                <Accordion title="Does CoCart work with WooCommerce extensions?">
                    Yes. CoCart is built on WooCommerce's Data Stores API and mirrors most WooCommerce hooks, so extensions like Subscriptions, Memberships, and dynamic pricing work out of the box. See the [integrations overview](/integrations) for details.
                </Accordion>

                <Accordion title="What happens when my annual subscription expires?">
                    Your plugin continues to work — nothing breaks. You just stop receiving updates and support until you renew. The Community edition is free forever with no subscription required.
                </Accordion>

                <Accordion title="Can I use CoCart without the SDK?">
                    Absolutely. CoCart is a standard REST API. You can call it with `fetch`, `cURL`, Axios, or any HTTP client in any language. The SDK is a convenience layer, not a requirement.
                </Accordion>

                <Accordion title="How does session management work without cookies?">
                    CoCart uses database-backed cart keys instead of cookies. The cart key is passed via an `X-Cart-Key` header, which works across SPAs, mobile apps, SSR, and any client that can send HTTP headers. No cookie consent banners needed.
                </Accordion>

                <Accordion title="Does CoCart slow down my WordPress site?">
                    No. CoCart is purpose-built for API performance. It adds one database table for session management and only loads when API requests are made. Your WordPress admin and frontend remain unaffected.
                </Accordion>
            </AccordionGroup>
