The ElysiaJS adapter provides CoCart integration for building WooCommerce API backends on Bun. ElysiaJS is a Bun-first web framework with end-to-end type safety, and this adapter reads the cart key directly from the standard `Request` object available in every handler.

## How It Works

1. **Client**: The frontend sends an `X-Cart-Key` header with each request to identify the cart.
2. **Server**: The adapter reads `X-Cart-Key` from the `Request` object via `request.headers.get('X-Cart-Key')`.
3. **Response**: The route handler uses the CoCart client to interact with WooCommerce and returns the result.

No cookies are used at any point — avoiding GDPR consent requirements, CORS restrictions, and cookie size limits.

## Server Client

Create a CoCart client inside any Elysia route handler. The cart key is read from the incoming request's `X-Cart-Key` header:

```ts
import { Elysia } from 'elysia';
import { createServerClient } from '@cocartheadless/sdk/elysiajs';

const app = new Elysia()
  .get('/cart', async ({ request }) => {
    const client = createServerClient(Bun.env.COCART_STORE_URL!, request);
    const cart = await client.cart().get();
    return cart.toObject();
  })
  .listen(3000);
```

### With Authentication

To access a logged-in customer's cart, pass their credentials via Basic Auth:

```ts
import { Elysia } from 'elysia';
import { createServerClient } from '@cocartheadless/sdk/elysiajs';

const app = new Elysia()
  .get('/cart', async ({ request }) => {
    const client = createServerClient(Bun.env.COCART_STORE_URL!, request, {
      username: 'customer@email.com',
      password: 'customer_password',
    });

    const cart = await client.cart().get();
    return cart.toObject();
  });
```

## Route Examples

Use the server client across multiple routes for full cart CRUD and product listing:

```ts
import { Elysia } from 'elysia';
import { createServerClient } from '@cocartheadless/sdk/elysiajs';

const app = new Elysia()
  .get('/api/cart', async ({ request }) => {
    const client = createServerClient(Bun.env.COCART_STORE_URL!, request);
    const cart = await client.cart().get();
    return cart.toObject();
  })
  .post('/api/cart/add', async ({ request, body }) => {
    const client = createServerClient(Bun.env.COCART_STORE_URL!, request);
    const { productId, quantity } = body as { productId: string; quantity: number };

    const response = await client.cart().addItem(productId, { quantity });
    return response.toObject();
  })
  .delete('/api/cart/:itemKey', async ({ request, params }) => {
    const client = createServerClient(Bun.env.COCART_STORE_URL!, request);
    const response = await client.cart().removeItem(params.itemKey);
    return response.toObject();
  })
  .get('/api/products', async ({ request }) => {
    const client = createServerClient(Bun.env.COCART_STORE_URL!, request);
    const products = await client.products().list({ per_page: 12 });
    return products.toObject();
  })
  .listen(3000);
```

## Plugin

Create a reusable Elysia plugin using `derive` to inject the CoCart client into every handler's context:

```ts
import { Elysia } from 'elysia';
import { createServerClient } from '@cocartheadless/sdk/elysiajs';

const cocartPlugin = new Elysia({ name: 'cocart' })
  .derive(({ request }) => ({
    cocart: createServerClient(Bun.env.COCART_STORE_URL!, request),
  }));

const app = new Elysia()
  .use(cocartPlugin)
  .get('/api/cart', async ({ cocart }) => {
    const cart = await cocart.cart().get();
    return cart.toObject();
  })
  .post('/api/cart/add', async ({ cocart, body }) => {
    const { productId, quantity } = body as { productId: string; quantity: number };
    const response = await cocart.cart().addItem(productId, { quantity });
    return response.toObject();
  })
  .listen(3000);
```

## Full Example

A complete ElysiaJS app with CORS, error handling, and full cart CRUD:

```ts
import { Elysia } from 'elysia';
import { cors } from '@elysiajs/cors';
import { createServerClient } from '@cocartheadless/sdk/elysiajs';

const cocartPlugin = new Elysia({ name: 'cocart' })
  .derive(({ request }) => ({
    cocart: createServerClient(Bun.env.COCART_STORE_URL!, request),
  }));

const app = new Elysia()
  .use(cors())
  .use(cocartPlugin)
  .onError(({ error }) => {
    return {
      error: error.message,
      status: 'error',
    };
  })
  // Get cart
  .get('/api/cart', async ({ cocart }) => {
    const cart = await cocart.cart().get();
    return cart.toObject();
  })
  // Add item to cart
  .post('/api/cart/add', async ({ cocart, body }) => {
    const { productId, quantity } = body as { productId: string; quantity: number };
    const response = await cocart.cart().addItem(productId, { quantity });
    return response.toObject();
  })
  // Update item quantity
  .put('/api/cart/:itemKey', async ({ cocart, params, body }) => {
    const { quantity } = body as { quantity: number };
    const response = await cocart.cart().updateItem(params.itemKey, { quantity });
    return response.toObject();
  })
  // Remove item from cart
  .delete('/api/cart/:itemKey', async ({ cocart, params }) => {
    const response = await cocart.cart().removeItem(params.itemKey);
    return response.toObject();
  })
  // Clear cart
  .post('/api/cart/clear', async ({ cocart }) => {
    const response = await cocart.cart().clear();
    return response.toObject();
  })
  // List products
  .get('/api/products', async ({ cocart }) => {
    const products = await cocart.products().list({ per_page: 12 });
    return products.toObject();
  })
  // Get single product
  .get('/api/products/:id', async ({ cocart, params }) => {
    const product = await cocart.products().get(params.id);
    return product.toObject();
  })
  .listen(3000);

console.log(`Server running at http://localhost:${app.server?.port}`);
```

## Environment Variables

```bash
# .env
COCART_STORE_URL=https://your-store.com
```

Bun reads `.env` files automatically — no additional packages needed. Access variables via `Bun.env.VAR_NAME`.

## Browser Client

If your ElysiaJS app serves a frontend (for example, via static files or an HTML template), you can use `createBrowserClient` and `attachCartKeyHeader` on the client side:

```ts
import { createBrowserClient, attachCartKeyHeader } from '@cocartheadless/sdk/elysiajs';

const client = createBrowserClient('https://your-store.com', {
  encryptionKey: 'your-secret-encryption-key',
});

await client.restoreSession();
attachCartKeyHeader(client);
```

This is primarily useful when your Elysia server doubles as a full-stack app. For API-only backends, the server client is all you need.

## How `attachCartKeyHeader` Works

`attachCartKeyHeader()` wraps `globalThis.fetch` so that every same-origin request automatically includes an `X-Cart-Key` header with the current cart key:

- Server route handlers receive the cart key without cookies
- Cross-origin requests are never modified
- If no cart key is set, no header is added

Call it once after creating the browser client and restoring the session.
