Use the CoCart SDK in [Webflow](https://webflow.com/) to add headless WooCommerce cart functionality to your Webflow site. Since Webflow doesn't support npm packages, you load the SDK from a CDN via a `<script>` tag.

## Setup

### 1. Add the SDK Script

In your Webflow project, go to **Project Settings > Custom Code** and paste the following into the **Footer Code** section (before `</body>` tag):

```html
<script src="https://cdn.jsdelivr.net/npm/@cocartheadless/sdk/dist/index.global.js"></script>
```

Or use unpkg:

```html
<script src="https://unpkg.com/@cocartheadless/sdk/dist/index.global.js"></script>
```

This loads the SDK globally as `window.CoCart`, making it available to all custom code on every page.

<Tip>
  Pin a specific version to avoid unexpected changes:

  ```html
  <!-- jsDelivr -->
  <script src="https://cdn.jsdelivr.net/npm/@cocartheadless/sdk@1.1.0/dist/index.global.js"></script>

  <!-- unpkg -->
  <script src="https://unpkg.com/@cocartheadless/sdk@1.1.0/dist/index.global.js"></script>
  ```
</Tip>

### 2. Initialize the SDK

Add a second `<script>` block below the SDK script (or in a page-level custom code section) to initialize the client:

```html
<script>
  var client = new CoCart("https://your-store.com");
</script>
```

### 3. Display a Cart Counter

Give an element (e.g., a text block) a custom attribute or ID like `id="cart-count"`, then update it dynamically:

```html
<script>
  var client = new CoCart("https://your-store.com");

  document.addEventListener("DOMContentLoaded", function () {
    client.cart().get().then(function (cart) {
      var el = document.getElementById("cart-count");
      if (el) {
        el.textContent = cart.get("item_count") || "0";
      }
    });
  });
</script>
```

### 4. Display Products

Create a container element with `id="product-list"` in the Webflow Designer, then populate it with product data:

```html
<script>
  var client = new CoCart("https://your-store.com");

  document.addEventListener("DOMContentLoaded", function () {
    client.products().all({ per_page: "6" }).then(function (response) {
      var container = document.getElementById("product-list");
      var products = response.toArray();

      products.forEach(function (product) {
        var card = document.createElement("div");
        card.className = "product-card";
        card.innerHTML =
          '<img src="' + product.images[0].src + '" alt="' + product.name + '">' +
          "<h3>" + product.name + "</h3>" +
          "<p>" + product.price + "</p>" +
          '<button data-product-id="' + product.id + '">Add to Cart</button>';
        container.appendChild(card);
      });
    });
  });
</script>
```

### 5. Add to Cart

Handle click events on your "Add to Cart" buttons:

```html
<script>
  var client = new CoCart("https://your-store.com");

  document.addEventListener("click", function (e) {
    var button = e.target.closest("[data-product-id]");
    if (!button) return;

    var productId = parseInt(button.getAttribute("data-product-id"), 10);
    button.textContent = "Adding...";

    client.cart().addItem(productId, 1).then(function () {
      button.textContent = "Added!";
      setTimeout(function () {
        button.textContent = "Add to Cart";
      }, 2000);
    });
  });
</script>
```

## Authenticating Customers

By default, the SDK operates as a guest — each visitor gets their own cart session automatically. To support registered customers (personal carts, saved addresses, order history), use [JWT authentication](/authentication/jwt).

<Warning>
  Never use Basic Auth (username/password) in Webflow. Since all code runs in the browser, credentials would be visible to anyone inspecting the page. JWT tokens are short-lived and auto-refresh, making them safe for client-side use.
</Warning>

### Login with JWT

Create a login form in the Webflow Designer with `id="login-form"`, an email input with `id="login-email"`, a password input with `id="login-password"`, and a status element with `id="login-status"`:

```html
<script>
  var client = new CoCart("https://your-store.com");

  document.addEventListener("DOMContentLoaded", function () {
    var form = document.getElementById("login-form");

    form.addEventListener("submit", function (e) {
      e.preventDefault();

      var email = document.getElementById("login-email").value;
      var password = document.getElementById("login-password").value;
      var status = document.getElementById("login-status");

      status.textContent = "Logging in...";

      client.login(email, password).then(function (response) {
        status.textContent = "Welcome, " + response.get("display_name") + "!";

        // The client now uses JWT for all subsequent requests
        // The customer's personal cart is loaded automatically
      }).catch(function () {
        status.textContent = "Login failed. Check your credentials.";
      });
    });
  });
</script>
```

### Logout

Add a logout button with `id="logout-btn"`:

```html
<script>
  document.addEventListener("DOMContentLoaded", function () {
    var logoutBtn = document.getElementById("logout-btn");

    logoutBtn.addEventListener("click", function () {
      client.logout().then(function () {
        // Client reverts to guest mode with a fresh cart session
        logoutBtn.textContent = "Logged out";
      });
    });
  });
</script>
```

### Show or Hide Elements Based on Auth Status

Toggle visibility of login/account elements depending on whether the customer is authenticated:

```html
<script>
  document.addEventListener("DOMContentLoaded", function () {
    var loginLink = document.getElementById("login-link");
    var accountLink = document.getElementById("account-link");

    if (client.isAuthenticated()) {
      loginLink.style.display = "none";
      accountLink.style.display = "block";
    } else {
      loginLink.style.display = "block";
      accountLink.style.display = "none";
    }
  });
</script>
```

### Guest-to-Customer Cart Transfer

When a guest adds items to the cart and then logs in, their guest cart is merged into their customer cart:

```html
<script>
  // Guest adds items before logging in
  client.cart().addItem(123, 2);

  // Later, when the guest logs in, their items are preserved
  client.login(email, password).then(function () {
    // Fetch the merged cart
    client.cart().get().then(function (cart) {
      console.log("Cart items after login:", cart.getItems());
    });
  });
</script>
```

<Tip>
  The [CoCart JWT Authentication](https://wordpress.org/plugins/cocart-jwt-authentication/) plugin (v3.0+) must be installed on your WordPress site for `client.login()` to work. See the [JWT setup guide](/authentication/jwt) for installation steps.
</Tip>

## Page-Level vs Site-Level Code

| Scope | Where to add | Runs on | Best for |
|---|---|---|---|
| **Site-level** | Project Settings > Custom Code | Every page | Loading the SDK script and initializing the client |
| **Page-level** | Page Settings > Custom Code | Single page | Page-specific logic like a product listing or checkout |

## Important Considerations

<Info>
  **DOM timing.** Always wrap your code in a `DOMContentLoaded` listener to ensure Webflow's elements are rendered before your script tries to access them.
</Info>

<Warning>
  **No server-side rendering.** Webflow sites are client-side only, so all API calls happen in the browser. Never expose sensitive credentials (consumer keys/secrets) — use guest sessions or [JWT authentication](/authentication/jwt) instead.
</Warning>

<Tip>
  **Webflow Interactions.** You can trigger Webflow's built-in interactions from custom code by dispatching events or toggling CSS classes after SDK calls complete. For example, add a `.cart-open` class to a cart drawer element after adding an item.
</Tip>

### CORS

Your WooCommerce store must allow requests from your Webflow domain. First enable [CORS](/cors), then restrict it to your domain. Add both filters to your theme's `functions.php` or a custom plugin:

```php
// Enable CORS
add_filter( 'cocart_disable_all_cors', function() { return false; } );

// Restrict to your Webflow domain
add_filter( 'cocart_allow_origin', function() {
    return 'https://your-site.webflow.io';
} );
```

See the [CORS documentation](/cors) for more details.

## FAQ

<AccordionGroup>
  <Accordion title="Can I use npm packages in Webflow?">
    No. Webflow doesn't support npm or module bundlers. You must load the SDK via a CDN `<script>` tag, which makes it available as `window.CoCart` (or just `CoCart`).
  </Accordion>

  <Accordion title="Should I put the SDK script in the header or footer?">
    Add the SDK `<script>` tag in the **Footer Code** section (Project Settings > Custom Code). This ensures it doesn't block page rendering. Your initialization code should go in a separate `<script>` block after it.
  </Accordion>

  <Accordion title="Can I use Basic Auth to authenticate customers?">
    No. Webflow runs entirely in the browser, so any credentials in your code are visible to end users. Use [JWT authentication](/authentication/jwt) instead — tokens are short-lived and auto-refresh safely on the client side.
  </Accordion>

  <Accordion title="How do I persist the cart across page navigations?">
    The SDK automatically stores the [cart key](/knowledge-base/cart-key) in `localStorage`. When the visitor navigates to another page, the same cart key is used and their cart is restored.
  </Accordion>

  <Accordion title="Do I need to configure CORS?">
    Yes. You must first enable CORS with the `cocart_disable_all_cors` filter, then restrict the allowed origin to your Webflow domain (e.g., `your-site.webflow.io`) using `cocart_allow_origin`. See the [CORS guide](/cors).
  </Accordion>

  <Accordion title="Why do I need DOMContentLoaded?">
    Webflow renders its elements before custom scripts run, but the timing isn't guaranteed. Wrapping your code in a `DOMContentLoaded` listener ensures all elements with IDs and attributes exist before your script tries to access them.
  </Accordion>

  <Accordion title="Can I trigger Webflow Interactions from the SDK?">
    Yes. After an SDK call completes (e.g., adding to cart), you can toggle CSS classes or dispatch custom events to trigger Webflow's built-in Interactions. For example, add a `.cart-open` class to a cart drawer element to animate it open.
  </Accordion>

  <Accordion title="How do I handle errors from the API?">
    Use `.catch()` on your promise chains. The SDK returns errors with a `code` and `message` you can display to the user. See the [error handling guide](/sdk/typescript/error-handling) for details.
  </Accordion>
</AccordionGroup>
