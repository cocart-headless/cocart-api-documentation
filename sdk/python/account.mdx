The account endpoint gives an authenticated customer access to their own profile, order history, downloads, and reviews via the fixed `cocart/v2/my-account` route. All methods require the customer to be authenticated via Basic Auth or JWT — guest access is not supported (except the dedicated guest order/download lookups below).

Access the account endpoint via `client.account()`.

<Note>
  If the CoCart plugin providing this route isn't installed, any account method raises a `cocart_plugin_required` error.
</Note>

## Authentication

Every account call must be made as an authenticated user. Set credentials when creating the client:

```python
from cocart import CoCart

# Basic Auth
client = CoCart("https://your-store.com",
    username="customer@example.com",
    password="their-password",
)

# JWT (requires CoCart JWT Authentication plugin)
client = CoCart("https://your-store.com")
client.login("customer@example.com", "their-password")
```

See [Authentication](/sdk/python/authentication) for the full guide including JWT auto-refresh.

## Profile

### Get Profile

```python
response = client.account().get_profile()
```

### Update Profile

```python
response = client.account().update_profile({
    "account_first_name": "John",
    "account_last_name": "Doe",
    "account_display_name": "John Doe",
    "account_email": "john@example.com",
})
```

### Change Password

```python
response = client.account().change_password(
    current="old-password",
    password="new-password",
    confirm="new-password",
)
```

## Orders

### List Orders

```python
response = client.account().get_orders()

# With parameters
response = client.account().get_orders({"page": "2", "per_page": "10", "order": "DESC"})
```

### Get a Single Order

```python
response = client.account().get_order(123)
```

### Get a Guest Order

Look up a guest order by ID and the billing email used when placing it — no auth required:

```python
response = client.account().get_guest_order(123, "customer@email.com")
```

## Downloads

### All Downloads

Returns every downloadable file available to the customer across all orders.

```python
response = client.account().get_downloads()
```

### Downloads for a Single Order

```python
response = client.account().get_order_downloads(123)
```

### Guest Order Downloads

For guest order look-up pages — no auth required, but the order ID and billing email must match:

```python
response = client.account().get_guest_order_downloads(123, "customer@email.com")
```

## Reviews

Returns the reviews the customer has submitted.

```python
response = client.account().get_reviews()
```

## Error Handling

Account methods inherit the standard SDK exception hierarchy. Authentication failures raise `AuthenticationException`, missing routes (plugin not installed) raise a `CoCartException` with error code `cocart_plugin_required`:

```python
from cocart.exceptions import CoCartException, AuthenticationException

try:
    profile = client.account().get_profile()
except AuthenticationException:
    # Redirect to login
    pass
except CoCartException as e:
    if e.error_code == "cocart_plugin_required":
        # Account API plugin is not installed on this store
        pass
    else:
        raise
```

See [Error Handling](/sdk/python/error-handling) for the full exception hierarchy.
