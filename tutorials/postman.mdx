[Postman](https://www.postman.com/) is a popular API client with a graphical interface for building, testing, and debugging HTTP requests. Importing the official CoCart OpenAPI specs gives you a ready-made collection of every endpoint, complete with request bodies, parameters, and example responses.

## Prerequisites

- [Postman](https://www.postman.com/downloads/) installed (desktop app recommended)
- A WordPress site with CoCart installed
- Your site URL (e.g. `https://yourstore.com`)

## Import the OpenAPI spec

CoCart publishes official OpenAPI 3.0.3 specs in the [`cocart-headless/cocart-openapi`](https://github.com/cocart-headless/cocart-openapi) repository. You can import directly from a URL — no download required.

### Option A: Import from URL

1. Open Postman and click **Import** in the top left
2. Select the **Link** tab
3. Paste the URL for the spec you need:

| Edition | URL |
|---------|-----|
| **CoCart Starter API v2** (recommended) | `https://raw.githubusercontent.com/cocart-headless/cocart-openapi/main/starter/v2/openapi-cocart-v2-collection.yaml` |
| **Community API v2** | `https://raw.githubusercontent.com/cocart-headless/cocart-openapi/main/community/v2/openapi-cocart-v2-stable.yaml` |
| **JWT Authentication** | `https://raw.githubusercontent.com/cocart-headless/cocart-openapi/main/jwt-authentication/openapi-cocart-jwt-auth.yaml` |
| **CoCart Plus API v1** | `https://raw.githubusercontent.com/cocart-headless/cocart-openapi/main/plus/v1/openapi-cocart-plus-v1-collection.yaml` |

4. Click **Import**

Postman will create a collection with all endpoints organized by tag.

### Option B: Import from file

1. Download the spec file from the [cocart-openapi repository](https://github.com/cocart-headless/cocart-openapi)
2. In Postman, click **Import** → **Files** → select the downloaded YAML file
3. Click **Import**

<Tip>
  Import multiple specs to get separate collections for the core API, JWT authentication, and Plus add-on endpoints.
</Tip>

## Set up your environment

Create an environment so you can switch between local, staging, and production stores without editing each request.

1. Click **Environments** in the sidebar
2. Click **+** to create a new environment (e.g. "CoCart Local")
3. Add these variables:

| Variable | Type | Example Value |
|----------|------|---------------|
| `protocol` | Default | `https` |
| `host` | Default | `yourstore.com` |
| `consumer_key` | Secret | `ck_xxxx` (for Sessions API only) |
| `consumer_secret` | Secret | `cs_xxxx` (for Sessions API only) |

4. Click **Save** and select the environment from the dropdown in the top right

The imported collection already uses `{{protocol}}` and `{{host}}` variables from the OpenAPI server definition, so requests will automatically target your configured store.

## Make your first request

1. Expand the imported **CoCart - API v2** collection in the sidebar
2. Select **Get Products** under the products group
3. Make sure your environment is selected
4. Click **Send**

You should see a JSON response with your store's products.

## Authentication

Most cart endpoints work without authentication (guest carts). For customer-specific carts or protected endpoints, you have two options:

### Basic Authentication

1. Select the request's **Authorization** tab
2. Choose **Basic Auth**
3. Enter the customer's username or email and password

### JWT Authentication

If you imported the JWT spec, you can authenticate with tokens:

1. First, log in through the **Login User** endpoint to get a JWT token
2. Copy the `jwt_token` from the response
3. On subsequent requests, go to the **Authorization** tab
4. Choose **Bearer Token** and paste the token

See [Authentication](/authentication/index) for more details.

## Generate code snippets

Postman can convert any request into code for your application:

1. Open a request and click **Send** to verify it works
2. Click the **Code snippet** icon on the right sidebar
3. Choose your language — PHP, JavaScript, Python, cURL, and more
4. Copy the generated code into your project

This is a quick way to bootstrap API calls in your application.

## Tips

- **Use the Console** (`Ctrl/Cmd + Alt + C`) to inspect raw HTTP traffic when debugging
- **Save examples** — after a successful response, click **Save as Example** to document expected responses
- **Use Collection Runner** to execute multiple requests in sequence, such as creating a cart, adding items, and checking out
- **Set up Pre-request Scripts** to automatically refresh JWT tokens before each request
