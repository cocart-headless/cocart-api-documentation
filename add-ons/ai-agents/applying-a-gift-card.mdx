Agents with the `cart:gift_card` scope can apply a gift card code directly, when WooCommerce Gift Cards is active.

<Note>
  `POST /wp-json/cocart/ai/v1/agent/cart/gift-card` — requires an agent token with `cart:gift_card` scope.
</Note>

<ParamField body="code" type="string" required>
  The gift card code to apply, e.g. `GIFT-ABCD-1234`.
</ParamField>

**Response:** `200 OK` with the updated cart summary, or `422 Unprocessable Entity` for an invalid code. Applied gift cards also appear as a redacted line in the `order_summary` shown in `202` responses and approval emails.
