Every approved order deducts its total from the token's running `spent_total` — in the same database transaction as order creation (`payment_token` mode) or at the point the redirect is generated (`approval_only` mode).

<Check>
  If a pending order would push spending past `max_spend`, checkout is blocked with a spend-limit error **before** any approval email goes out — a customer never gets asked to approve something already destined to fail on spend grounds.
</Check>

<Note>
  `max_spend` is denominated in the `currency` set at token issuance. CoCart AI does not perform currency conversion when checking spend limits, so multi-currency stores should keep that in mind.
</Note>
