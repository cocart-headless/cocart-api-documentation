Add-ons are separate CoCart plugins that build on top of an existing CoCart plugin to add a specific piece of functionality. Unlike [integrations](/integrations), which make CoCart work correctly alongside a third-party plugin, add-ons introduce new REST endpoints and response data of their own.

Each add-on requires its own license key. See [License Activation](/getting-started/license-activation) for how to activate it.
