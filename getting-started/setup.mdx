### Before you start

It’s important that your [server requirements](https://woocommerce.com/document/server-requirements/) meet the minimum that WooCommerce ask for in order to run CoCart.

If you already have WooCommerce installed with products ready to sell, you meet the requirements to install CoCart.

<Note>
    If you are new to CoCart and simply want to test it out, you can download the community edition of CoCart from the WordPress plugin repository. This version is free to use and has a limited set of features compared to the premium version, but it’s a great way to get started and see how CoCart works. [Install CoCart Community](/community/install)
</Note>

### Pricing & Purchase

CoCart’s premium plugins are available on the [pricing page](https://cocartapi.com/pricing/). Once you have completed your purchase, you will be able to download the plugin from your [Polar account](https://polar.sh/cocartheadless/portal/request).

### After Purchase

Once you have completed your purchase, take these steps before installing the plugin.

<Steps>
    <Step title="Download from Polar">
        Go to your [Polar account library](https://polar.sh/cocartheadless/portal/request), find your purchase, and download the `.zip` file.
    </Step>
    <Step title="Accept the GitHub repository invitation">
        Check your email for an invitation to the plugin's private GitHub repository and accept it. This gives you access to source releases and future updates.
    </Step>
    <Step title="Join Discord for support">
        Check your email for a Discord invitation, accept it, and join the CoCart Discord server. All premium plugin support is provided there.
    </Step>
</Steps>

### Upload Install

Once you have the plugin downloaded, log in to your WordPress dashboard, navigate to the ‘Plugins’ menu and press ‘Add New’. Then press ‘Upload Plugin’.

You will either be redirected to a new page or the upload field will simple appear at the top allowing you to upload the plugin. Once the file is selected, press ‘Install Now’.

<Card title="Upload Plugin" img="https://cocartapi.com/wp-content/uploads/2023/11/image.png"/>

Once the plugin is installed. Press ‘Activate Plugin’.

<Card title="Activate CoCart" img="https://cocartapi.com/wp-content/uploads/2023/11/image-1.png"></Card>

### Install via FTP

Open your FTP program of choice and login to your FTP server. Access where your WordPress plugins folder is stored and upload the folder of the plugin that is in the zip file and put it in the plugins directory.

Now log in to your WordPress dashboard, navigate to the ‘Plugins’ menu and press ‘Activate’ where CoCart is listed.

<Card title="Upload Plugin" img="https://cocartapi.com/wp-content/uploads/2023/11/image-4.png"></Card>

## Prerequisites

Before using CoCart, ensure your WordPress permalinks are configured to any setting except "Plain". This configuration is essential for accessing the REST API using standard endpoint URIs (e.g. `cocart/v2/products`).

Configure this under **Settings > Permalinks**.

<Card title="Permalink Settings" img="https://cocartapi.com/wp-content/uploads/2023/11/image-3.png"></Card>

With these settings in place, you're ready to begin using CoCart.

## WooCommerce Dependency

CoCart requires an active WooCommerce installation to function. If WooCommerce is not installed or is deactivated, CoCart will automatically disable itself during activation to prevent technical issues.

You'll see a prompt to install or activate WooCommerce if needed.

<Card title="Admin notice requesting WooCommerce" img="https://cocartapi.com/wp-content/uploads/2023/11/image-2.png"></Card>

## Troubleshooting

<AccordionGroup>
    <Accordion title="The downloaded file is a folder, not a .zip file">
        Your browser may be automatically unzipping the archive after download. Check your browser's download settings and disable automatic extraction, then download the plugin again from your [Polar account](https://polar.sh/cocartheadless/portal/request).
    </Accordion>

    <Accordion title="Uploaded file exceeds the maximum upload size">
        Your host limits the maximum file upload size. You will see an error like: `The uploaded file exceeds the upload_max_filesize directive in php.ini`. Either increase the `upload_max_filesize` and `post_max_size` values in your `php.ini` (or ask your host to do so), or install the plugin [via FTP](#install-via-ftp) instead.
    </Accordion>

    <Accordion title="Destination folder already exists">
        WordPress shows this error when a previous installation of the plugin was not fully removed. Delete the existing plugin folder from `wp-content/plugins/` via FTP or your host's file manager, then attempt the upload again.
    </Accordion>

    <Accordion title="Could not create directory">
        This is a file permission issue on your server. The WordPress files directory needs write permissions. Contact your host and ask them to verify that the `wp-content/plugins/` directory has the correct permissions.
    </Accordion>

    <Accordion title="White screen or fatal error on activation">
        A blank screen or fatal error after activating usually means a PHP memory limit has been reached or a conflict exists with another plugin or theme. Try increasing your PHP memory limit to at least 256MB, then deactivate other plugins one by one to identify any conflict.
    </Accordion>

    <Accordion title="CoCart deactivated itself after activation">
        CoCart requires WooCommerce to be installed and active. If WooCommerce is missing or deactivated, CoCart will automatically disable itself. Install and activate WooCommerce first, then activate CoCart again.
    </Accordion>

    <Accordion title="REST API endpoints return a 404">
        Your WordPress permalinks are likely set to **Plain**. CoCart's REST API requires any permalink structure other than Plain. Go to **Settings > Permalinks**, choose any other option, and save.
    </Accordion>
</AccordionGroup>
