<Warning>
    This API requires **CoCart Plus v2 or higher** to use.
</Warning>

<Info>
    This endpoint is public and does not require a cart session. Use it to build a checkout form: field configuration, locale and country/state lists, shipping and account settings, store settings, and client-side validation rules.
</Info>
