<Warning>
    This API requires **CoCart Plus v2 or higher** to use.
</Warning>

<Info>
    Changes the subscription's payment method via the `cocart_my_account_update_subscription_payment_method` filter. What actually happens differs by plugin - WooCommerce Subscriptions accepts any valid gateway ID and runs a real $0 validation charge against the new method before accepting it, while Milo Subscriptions requires `token_id` and does a pure saved-token swap with no charge.
</Info>
