<Warning>
    This API requires **CoCart Plus v2 or higher** to use.
</Warning>

<Info>
    Subscriptions are provided by whichever subscription-plugin extension is active (e.g. [WooCommerce Subscriptions](https://woocommerce.com/products/woocommerce-subscriptions/), Milo Subscriptions) via the `cocart_my_account_get_subscriptions` filter, so results are the same regardless of which subscription plugin the store runs. Requires a subscription-plugin extension to be active; no subscriptions are returned otherwise.
</Info>
