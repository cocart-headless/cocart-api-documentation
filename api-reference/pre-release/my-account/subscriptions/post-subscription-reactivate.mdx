tag: "New"
robots: "noindex, follow"
---

<Warning>
    This API requires **CoCart Plus v2 or higher** to use.
</Warning>

<Info>
    Reactivates the subscription via the `cocart_my_account_reactivate_subscription` filter. A subscription that needs a renewal payment first is rejected rather than reactivated, matching WooCommerce Subscriptions' own My Account behavior; other subscription plugins may reject for different reasons.
</Info>
