<Warning>
    This API requires **CoCart Plus v2 or higher** to use.
</Warning>

<Info>
    Resubscribing isn't a single atomic action in either WooCommerce Subscriptions or Milo Subscriptions - both re-add the old subscription's items to the cart and send the customer through checkout, where the plugin's own order-creation hooks link the new order back to the old subscription. This endpoint only seeds the active cart the same way, via the `cocart_my_account_seed_resubscribe_cart` filter; the client then completes the purchase through CoCart's existing checkout endpoints. No payment is processed here.

    Seeding empties whatever the customer already had in their cart, so a non-empty cart is snapshotted into the session first - `DELETE` on this same route restores that snapshot and discards the in-progress resubscribe attempt.
</Info>
