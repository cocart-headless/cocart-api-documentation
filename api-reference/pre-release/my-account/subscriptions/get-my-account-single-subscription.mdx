<Warning>
    This API requires **CoCart Plus v2 or higher** to use.
</Warning>

<Info>
    Guests may also view a subscription by providing the `email` query parameter matching the subscription's billing email address. To avoid leaking which subscription IDs exist, a non-existent subscription and one the requester doesn't own both return the same 404 response.
</Info>
