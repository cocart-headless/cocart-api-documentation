---
title: "Cancel Subscription"
openapi: "../../openapi-cocart-plus-v2-collection.yaml POST /my-account/subscriptions/{id}/cancel"
tag: "New"
robots: "noindex, follow"
---

<Warning>
    This API requires **CoCart Plus v2 or higher** to use.
</Warning>

<Info>
    Cancels the subscription via the `cocart_my_account_cancel_subscription` filter. Requires login - write actions never allow guest access by billing email. The exact error code, message and status for a rejected cancellation depend on the owning subscription plugin (e.g. [WooCommerce Subscriptions](https://woocommerce.com/products/woocommerce-subscriptions/), Milo Subscriptions).
</Info>
