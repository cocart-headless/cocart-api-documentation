<Warning>
    This API requires **CoCart Plus v2 or higher** to use.
</Warning>

<Info>
    Mirrors the classic My Account "Cancel order" action - order status is validated, an order note is added, and the `woocommerce_cancelled_order` action fires so stock restoration and any cancellation notifications hooked onto that action behave the same as cancelling from the classic My Account page. Only orders with a status of `pending` or `failed` can be cancelled by default (filterable via `cocart_get_account_orders_action_valid_statuses_for_cancel`).
</Info>
