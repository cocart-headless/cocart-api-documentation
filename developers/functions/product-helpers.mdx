### `CoCart_Utilities_Product_Helpers::get_product_image_sizes()`

Plugin: <Badge color="blue">Community</Badge>

Returns all registered image sizes available for product images, merged with `full` and `custom`.

<Note>Made available since v4.2.0</Note>

**Returns**: `array` — Image size names.

### `CoCart_Utilities_Product_Helpers::get_images()`

Plugin: <Badge color="blue">Community</Badge>

Returns all images (featured + gallery) for a product or product variation, each with `id`, `src` (keyed by size), `name`, `alt`, `position`, and `featured`. Falls back to the WooCommerce placeholder image when no images are set.

<Note>Made available since v3.1.0</Note>

**Parameters**

<ParamField query="product" type="WC_Product|WC_Product_Variation">
  The product object.
</ParamField>

**Returns**: `array` — Array of image data.

### `CoCart_Utilities_Product_Helpers::get_price_from_tax_display_mode()`

Plugin: <Badge color="blue">Community</Badge>

Returns the WooCommerce price function name (`wc_get_price_including_tax` or `wc_get_price_excluding_tax`) that matches the given tax display mode. Use the returned string as a callable alongside `cocart_format_money()` to format prices consistently with the Products API.

<Note>Made available since v3.1.0</Note>

**Parameters**

<ParamField query="tax_display_mode" type="string">
  Tax display mode: `incl` or `excl`.
</ParamField>

**Returns**: `string` — Function name to call for price calculation.

**Example**

```php
$tax_display_mode = CoCart_Utilities_Product_Helpers::get_tax_display_mode();
$price_function   = CoCart_Utilities_Product_Helpers::get_price_from_tax_display_mode( $tax_display_mode );

$formatted_price = cocart_format_money( $price_function( $product, array( 'price' => $product->get_price() ) ) );
```

### `CoCart_Utilities_Product_Helpers::get_variation_id_from_variation_data()`

Plugin: <Badge color="blue">Community</Badge>

Matches variation attributes from a request to a variation ID using the WooCommerce data store. Throws `CoCart_Data_Exception` if no match is found.

<Note>Made available since v2.1.2</Note>

**Parameters**

<ParamField query="request" type="array">
  Add-to-cart request params containing a `variation` key.
</ParamField>

<ParamField query="product" type="WC_Product">
  The parent variable product object.
</ParamField>

**Returns**: `int` — Matching variation ID.
