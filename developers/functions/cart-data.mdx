### `cocart_get_timestamp()`

Plugin: <Badge color="blue">Community</Badge>

Returns the timestamp the cart was created or expired.

<Note>Made available since v4.2.0</Note>

**Parameters**

<ParamField query="cart_key" type="string">
  The cart key.
</ParamField>

<ParamField query="timestamp_type" type="string">
  The type of timestamp. Accepts `created` or `expired`. Default: `created`.
</ParamField>

**Returns**: `string|null` — The timestamp or null if invalid type.

- **Defined in**: [`includes/cocart-core-functions.php`](https://github.com/co-cart/co-cart/blob/trunk/includes/cocart-core-functions.php)
