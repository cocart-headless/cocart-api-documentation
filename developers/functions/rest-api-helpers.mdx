### `cocart_prepare_date_response()`

Plugin: <Badge color="blue">Community</Badge>

Parses and formats a date for ISO8601/RFC3339 format.

<Note>Made available since v3.0.0</Note>

**Parameters**

<ParamField query="date" type="string|null|CoCart_DateTime">
  Date to format.
</ParamField>

<ParamField query="utc" type="bool">
  Send `false` to get local/offset time. Default: `true`.
</ParamField>

**Returns**: `string|null` — ISO8601/RFC3339 formatted datetime.

- **Defined in**: [`includes/cocart-rest-functions.php`](https://github.com/co-cart/co-cart/blob/trunk/includes/cocart-rest-functions.php)

### `cocart_add_to_cart_message()`

Plugin: <Badge color="blue">Community</Badge>

Add to cart messages. Forked from `wc_add_to_cart_message()` for REST API use without HTML context.

<Note>Made available since v3.0.0</Note>

**Parameters**

<ParamField query="products" type="int|array">
  List of Product IDs or single ID.
</ParamField>

<ParamField query="show_qty" type="bool">
  Should quantities be shown. Default: `false`.
</ParamField>

<ParamField query="return_msg" type="bool">
  Return message rather than add it. Default: `false`.
</ParamField>

**Returns**: `mixed` — Message string or void.

- **Defined in**: [`includes/cocart-rest-functions.php`](https://github.com/co-cart/co-cart/blob/trunk/includes/cocart-rest-functions.php)

### `cocart_rest_should_load_namespace()`

Plugin: <Badge color="red">Starter</Badge>

Checks if a REST namespace should be loaded. Useful to maintain site performance by disabling unused API versions.

<Note>Made available since v5.0.0</Note>

**Parameters**

<ParamField query="ns" type="string">
  The namespace to check (e.g. `cocart/v1`, `cocart/v2`).
</ParamField>

<ParamField query="rest_route" type="string">
  The REST route being checked. Optional.
</ParamField>

**Returns**: `bool` — True if the namespace should be loaded.

- **Defined in**: [`includes/cocart-rest-functions.php`](https://github.com/co-cart/co-cart/blob/trunk/includes/cocart-rest-functions.php)
