### `cocart_format_money()`

Plugin: <Badge color="red">Starter</Badge>

Converts monetary values from store settings to string based integers, using the smallest unit of a currency.

<Note>Made available since v5.0.0</Note>

**Parameters**

<ParamField query="value" type="int|float|string">
  Value to format.
</ParamField>

<ParamField query="options" type="array">
  Options influencing formatting. Accepts `currency`, `decimals`, `rounding_mode`, and `trim_zeros`.
</ParamField>

**Returns**: `string` — Formatted value.

- **Defined in**: [`includes/cocart-formatting-functions.php`](https://github.com/co-cart/co-cart/blob/trunk/includes/cocart-formatting-functions.php)

### `cocart_round()`

Plugin: <Badge color="red">Starter</Badge>

Round a value with a rounding mode, compatible across PHP 7.4–8.5+. Handles both integer constants and `RoundingMode` enum.

<Note>Made available since v5.0.0</Note>

**Parameters**

<ParamField query="value" type="float">
  The value to round.
</ParamField>

<ParamField query="precision" type="int">
  Number of decimal digits. Default: `0`.
</ParamField>

<ParamField query="mode" type="int">
  Rounding mode constant. Default: `PHP_ROUND_HALF_UP`.
</ParamField>

**Returns**: `float` — The rounded value.

- **Defined in**: [`includes/cocart-formatting-functions.php`](https://github.com/co-cart/co-cart/blob/trunk/includes/cocart-formatting-functions.php)

### `cocart_format_variation_data()`

Plugin: <Badge color="red">Starter</Badge>

Formats the product attributes for a variation. Converts slugs such as `attribute_pa_size` to `Size`.

<Note>Made available since v5.0.0</Note>

**Parameters**

<ParamField query="attributes" type="array">
  Array of data from the cart.
</ParamField>

<ParamField query="product" type="WC_Product">
  The product object.
</ParamField>

**Returns**: `array` — Formatted attribute data.

- **Defined in**: [`includes/cocart-formatting-functions.php`](https://github.com/co-cart/co-cart/blob/trunk/includes/cocart-formatting-functions.php)

### `cocart_price_no_html()`

Plugin: <Badge color="blue">Community</Badge>

Formats the price with a currency symbol without HTML wrappers. Forked from `wc_price()` for REST API use.

<Note>Made available since v3.0.0</Note>

**Parameters**

<ParamField query="price" type="float">
  Raw price.
</ParamField>

<ParamField query="args" type="array">
  Formatting arguments. Accepts `ex_tax_label`, `currency`, `decimal_separator`, `thousand_separator`, `decimals`, and `price_format`.
</ParamField>

**Returns**: `string` — Formatted price string.

- **Defined in**: [`includes/cocart-rest-functions.php`](https://github.com/co-cart/co-cart/blob/trunk/includes/cocart-rest-functions.php)
