### `CoCart_Utilities_Cart_Helpers::get_cart_key()`

Plugin: <Badge color="blue">Community</Badge>

Returns the current session's cart key.

<Note>Made available since v3.0.0</Note>

**Returns**: `string` — The cart key, or empty string if unavailable.

### `CoCart_Utilities_Cart_Helpers::get_customer_fields()`

Plugin: <Badge color="blue">Community</Badge>

Returns the customer's checkout field values for a given field group (`billing` or `shipping`), including any custom meta-backed fields.

<Note>Made available since v3.0.0</Note>

**Parameters**

<ParamField query="fields" type="string">
  Field group to return. Accepts `billing` or `shipping`. Default: `billing`.
</ParamField>

<ParamField query="customer" type="WC_Customer|null">
  The customer object. Returns an empty array if not provided.
</ParamField>

**Returns**: `array` — Customer field key/value pairs.

### `CoCart_Utilities_Cart_Helpers::get_tax_display_mode()`

Plugin: <Badge color="blue">Community</Badge>

Returns the effective tax display mode for the **cart**, validating the supplied value against `incl` or `excl`. Falls back to the `woocommerce_tax_display_cart` option.

<Note>Made available since v4.3.8</Note>

<Tip>
  This is the cart equivalent of `CoCart_Utilities_Product_Helpers::get_tax_display_mode()`, which reads the shop setting. Use this one when working with cart totals and items; use the product helper when working with product prices.
</Tip>

**Parameters**

<ParamField query="tax_display_mode" type="string">
  Provided tax display mode. Optional — omit to read from store settings.
</ParamField>

**Returns**: `string` — `incl` or `excl`.
