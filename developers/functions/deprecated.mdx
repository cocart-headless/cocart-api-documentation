### `cocart_prepare_money_response()`

<Warning>
  **Deprecated:** v5.0.0 — Replaced with [cocart_format_money()](/developers/functions/formatting#cocart_format_money)
</Warning>

Convert monetary values from WooCommerce to string based integers.

<Note>Made available since v3.1.0</Note>

**Parameters**

<ParamField query="amount" type="string|float">
  Monetary amount with decimals.
</ParamField>

<ParamField query="decimals" type="int">
  Number of decimals. Default: `2`.
</ParamField>

<ParamField query="rounding_mode" type="int">
  Rounding mode. Default: `PHP_ROUND_HALF_UP`.
</ParamField>

**Returns**: `string` — The new amount.

- **Defined in**: [`includes/cocart-rest-functions.php`](https://github.com/co-cart/co-cart/blob/trunk/includes/cocart-rest-functions.php)
