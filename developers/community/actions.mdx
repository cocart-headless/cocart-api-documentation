This page lists every action hook available in the CoCart Community edition. Use these hooks to run custom code when CoCart performs key operations like adding items, clearing the cart, or saving session data.

<Tip>
Looking for hooks in other CoCart plugins? See [CoCart Starter actions](/developers/actions) or [JWT Authentication actions](/developers/jwt/actions).
</Tip>

## Installation Hooks

### `cocart_init`

Fires once the CoCart plugin has finished loading.

<Info>
    Made available since v3.0.0
</Info>

**Usage**
```php

    // Your code here
});
```

## Authentication

### `cocart_login_permission_granted`

Fires when login permission is successfully granted after authentication. Use this for audit logging, analytics, or post-authentication tasks like recording login history.

<Info>
    Made available since v4.8.0
</Info>

**Parameters**

<ParamField path="current_user" type="WP_User">
  The authenticated user object.
</ParamField>

<ParamField path="request" type="WP_REST_Request">
  The current REST API request.
</ParamField>

<ParamField path="endpoint" type="string">
  The endpoint being accessed (e.g. `'login'`).
</ParamField>

**Usage**
```php
add_action( 'cocart_login_permission_granted', function( $current_user, $request, $endpoint ) {
    // Log successful authentication
    error_log( sprintf(
        'CoCart login granted for user %d (%s) on endpoint: %s',
        $current_user->ID,
        $current_user->user_login,
        $endpoint
    ) );
}, 10, 3 );
```

<Tip>
See the [Authentication Injection tutorial](/tutorials/authentication-injection) for advanced examples including audit logging and security monitoring.
</Tip>

[Search `cocart_login_permission_granted` in repository](https://github.com/co-cart/co-cart/search?q=cocart_login_permission_granted&type=code)
