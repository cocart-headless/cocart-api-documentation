CoCart exposes a rich set of WordPress hooks and functions for extending and customizing its behavior. Use this section to find the right hook or function for your use case.

## Plugin Key Index

Badges throughout the developer reference identify which plugin each hook or filter is available in:

| Plugin    | Badge | Notes |
|-----------|-------|-------|
| Community | <Badge color="blue">Community</Badge> | Free plugin — [wordpress.org/plugins/cart-rest-api-for-woocommerce](https://wordpress.org/plugins/cart-rest-api-for-woocommerce/) |
| Starter   | <Badge color="red">Starter</Badge> | Paid plugin |
| Plus      | <Badge color="purple">Plus</Badge> | Paid plugin |
| JWT       | <Badge color="green">JWT</Badge> | Free add-on — [wordpress.org/plugins/cocart-jwt-authentication](https://wordpress.org/plugins/cocart-jwt-authentication/) |

<Info>
  Filters and action hooks in the Community plugin are also available in Starter unless stated otherwise. Hooks in Starter are not available in Community.
</Info>
