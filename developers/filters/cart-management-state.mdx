### `cocart_cart_expiration`

Plugin: <Badge color="blue">Community</Badge>

Filter allows you to change the amount of time before the cart has expired. Default is ```(DAY_IN_SECONDS * 2)``` = 2 Days - Previously 7 days.

<Note>Made available since v2.1.0</Note>

**Parameters**

<ParamField query="$expiration" type="int">
  Expiration.
</ParamField>

<ParamField query="$is_user_logged_in" type="boolean">
  If user is logged in. **@since v4.4.0**
</ParamField>

**Usage**
```php
add_filter( 'cocart_cart_expiration', function( $expiration, $is_user_logged_in ) {
    // Extend cart expiration for logged-in users to 14 days.
    if ( $is_user_logged_in ) {
        return WEEK_IN_SECONDS * 2;
    }

    // Fallback to 2 days for guest users.
    return $expiration;
}, 10, 2 );
```

### `cocart_cart_extensions`

Plugin: <Badge color="red">Basic</Badge>

Filters the extensions data appended to the cart response under the `extensions` key. Only applied when at least one callback is hooked. Use this to add custom data from your add-on or integration without modifying the core cart response structure.

<Note>Made available since v5.0.0</Note>

**Parameters**

<ParamField query="extension_data" type="array">
  The extensions data array. Empty by default.
</ParamField>

<ParamField query="cart" type="array">
  The full cart data array.
</ParamField>

<ParamField query="request" type="WP_REST_Request">
  The request object.
</ParamField>

<ParamField query="cart_instance" type="object">
  The cart instance.
</ParamField>

**Usage**
```php
add_filter( 'cocart_cart_extensions', function( $extension_data, $cart, $request, $cart_instance ) {
    // Only return loyalty points for authenticated customers.
    if ( is_user_logged_in() ) {
        $extension_data['my_plugin'] = array(
            'loyalty_points' => (int) get_user_meta( get_current_user_id(), 'loyalty_points', true ),
        );
    }
    return $extension_data;
}, 10, 4 );
```

### `cocart_cart_extensions_schema`

Plugin: <Badge color="red">Basic</Badge>

Filters the cart-level schema properties for the `extensions` key. Use this alongside `cocart_cart_extensions` to ensure the REST API schema accurately reflects any data your integration adds.

<Note>Made available since v5.0.0</Note>

**Parameters**

<ParamField query="properties" type="array">
  The schema properties to extend. Empty by default.
</ParamField>

**Usage**
```php
add_filter( 'cocart_cart_extensions_schema', function( $properties ) {
    $properties['my_plugin'] = array(
        'description' => __( 'My plugin extension data.', 'my-plugin' ),
        'type'        => 'object',
        'context'     => array( 'view', 'edit' ),
        'readonly'    => true,
        'properties'  => array(
            'loyalty_points' => array(
                'description' => __( 'Loyalty points for the authenticated customer. Not present for guest carts.', 'my-plugin' ),
                'type'        => 'integer',
                'context'     => array( 'view', 'edit' ),
                'readonly'    => true,
            ),
        ),
    );
    return $properties;
} );
```
