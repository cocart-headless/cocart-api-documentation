### `cocart_admin_menu_shortcuts`

Plugin: <Badge color="red">Basic</Badge>

Filter allows you to customize the admin menu shortcuts displayed in the CoCart admin pages.

<Note>Made available since v5.0.0</Note>

**Parameters**

<ParamField query="shortcuts" type="array">
  Array of admin menu shortcut items.
</ParamField>

**Usage**
```php
add_filter( 'cocart_admin_menu_shortcuts', function( $shortcuts ) {
    $shortcuts[] = array(
        'title' => 'My Custom Page',
        'url'   => admin_url( 'admin.php?page=my-custom-page' ),
    );
    return $shortcuts;
} );
```

### `cocart_admin_screens`

Plugin: <Badge color="purple">Plus</Badge>

Filters the list of admin screen page IDs where CoCart assets (scripts and styles) should be loaded.

<Note>Made available since v1.0.0 of CoCart Plus</Note>

**Parameters**

<ParamField query="screens" type="array">
  Array of screen IDs (e.g. `dashboard`, `plugins`, `toplevel_page_cocart`).
</ParamField>

**Usage**
```php
add_filter( 'cocart_admin_screens', function( $screens ) {
    // Load CoCart assets on your custom admin page
    $screens[] = 'my-custom-page';
    return $screens;
} );
```

### `cocart_plus_beta_notice_expiration`

Plugin: <Badge color="purple">Plus</Badge>

Filters the expiration time for dismissing the beta notice in the admin dashboard.

<Note>Made available since v1.0.0 of CoCart Plus</Note>

**Parameters**

<ParamField query="expiration_time" type="int">
  Time in seconds before the notice reappears. Default: `WEEK_IN_SECONDS * 2` (2 weeks).
</ParamField>

**Usage**
```php
add_filter( 'cocart_plus_beta_notice_expiration', function( $expiration_time ) {
    // Dismiss for 30 days instead
    return MONTH_IN_SECONDS;
} );
```

### `cocart_updates_screen_capability`

Plugin: <Badge color="purple">Plus</Badge>

Filters the required user capability to view the CoCart updates screen.

<Note>Made available since v1.0.0 of CoCart Plus</Note>

**Parameters**

<ParamField query="capability" type="string">
  The capability required. Default: `manage_options`.
</ParamField>

**Usage**
```php
add_filter( 'cocart_updates_screen_capability', function( $capability ) {
    // Allow shop managers to view updates
    return 'manage_woocommerce';
} );
```
