### `cocart_rest_should_load_namespace`

Plugin: <Badge color="red">Starter</Badge>

Filter allows you to determine whether a specific API namespace should be loaded. Use this to disable certain API namespaces for performance or security.

<Note>Made available since v5.0.0</Note>

**Parameters**

<ParamField query="should_load" type="boolean">
  Whether to load the namespace. Default: `true`.
</ParamField>

<ParamField query="namespace" type="string">
  The namespace being loaded (e.g. `'cocart/v2'`).
</ParamField>

**Usage**
```php
add_filter( 'cocart_rest_should_load_namespace', function( $should_load, $namespace ) {
    // Disable API v1 entirely
    if ( $namespace === 'cocart/v1' ) {
        return false;
    }
    return $should_load;
}, 10, 2 );
```

### `cocart_wp_disable_access`

Plugin: <Badge color="red">Starter</Badge>

Filter allows you to disable frontend access to the WordPress site entirely. When enabled, visitors are redirected to your headless storefront instead of seeing the WordPress theme.

<Note>Made available since v5.0.0</Note>

**Parameters**

<ParamField query="disable" type="string">
  Whether to disable WordPress frontend access. Accepts `yes` or `no`. Default: `no`.
</ParamField>

**Usage**
```php
add_filter( 'cocart_wp_disable_access', '__return_true' );
```

### `cocart_wp_accessible_page_ids`

Plugin: <Badge color="red">Starter</Badge>

Filter allows you to specify which WordPress page IDs remain accessible when frontend access is disabled. By default, cart and checkout pages remain accessible to support the [Load Cart from Session](/load-cart) feature.

<Note>Made available since v5.0.0</Note>

**Parameters**

<ParamField query="page_ids" type="array">
  Array of page IDs that remain accessible.
</ParamField>

**Usage**
```php
add_filter( 'cocart_wp_accessible_page_ids', function( $page_ids ) {
    // Also keep the privacy policy page accessible
    $page_ids[] = get_option( 'wp_page_for_privacy_policy' );
    return $page_ids;
} );
```

### `cocart_is_local_site`

Plugin: <Badge color="purple">Plus</Badge>

Filters whether the current site is detected as a local development environment.

<Note>Made available since v1.0.0 of CoCart Plus</Note>

**Parameters**

<ParamField query="is_local" type="bool">
  Whether the site is a local development site.
</ParamField>

**Usage**
```php
add_filter( 'cocart_is_local_site', function( $is_local ) {
    // Treat custom TLD as local
    if ( strpos( site_url(), '.test' ) !== false ) {
        return true;
    }
    return $is_local;
} );
```

### `cocart_known_staging`

Plugin: <Badge color="purple">Plus</Badge>

Filters the list of known staging environment patterns used to detect staging sites. Includes URL patterns and PHP constants to check.

<Note>Made available since v1.0.0 of CoCart Plus</Note>

**Parameters**

<ParamField query="known_staging" type="array">
  Array with `urls` (array of regex patterns) and `constants` (array of PHP constant names to check).
</ParamField>

**Usage**
```php
add_filter( 'cocart_known_staging', function( $known_staging ) {
    // Add your custom staging URL pattern
    $known_staging['urls'][] = '#\.staging\.yourcompany\.com#i';
    return $known_staging;
} );
```
