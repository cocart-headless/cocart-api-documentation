### `cocart_pre_insert_product_review`

Plugin: <Badge color="blue">Community</Badge>

Filters a review before it is inserted via the REST API. Allows modification of the review right before it is inserted via `wp_insert_comment()`. Returning a _WP_Error_ value from the filter will short circuit insertion and allow skipping further processing.

<Note>Made available since v2.1.0</Note>

**Parameters**

<ParamField query="prepared_review" type="array|WP_Error">
  The prepared review data for `wp_insert_comment()`.
</ParamField>

<ParamField query="request" type="WP_REST_Request">
  Full details about the request.
</ParamField>

**Usage**
```php
add_filter( 'cocart_pre_insert_product_review', function() {
    // Your code here
}, 10 );
```

### `cocart_product_insert_review_status`

Plugin: <Badge color="red">Starter</Badge>

Filter allows you to change the default status for new product reviews submitted via the API. By default, reviews are set to `hold` for moderation.

<Note>Made available since v5.0.0</Note>

**Parameters**

<ParamField query="status" type="string">
  Review status. Default: `hold`. Only `approved` is accepted as an alternative — any other value resets to `hold`.
</ParamField>

**Usage**
```php
add_filter( 'cocart_product_insert_review_status', function( $status ) {
    // Auto-approve reviews (use with caution)
    return 'approved';
} );
```

### `cocart_product_review_collection_params`

Plugin: <Badge color="blue">Community</Badge>

Filter collection parameters for the reviews controller. This filter registers the collection parameter, but does not map the collection parameter to an internal _WP_Comment_Query_ parameter. Use the `cocart_product_review_query` filter to set _WP_Comment_Query_ parameters.
