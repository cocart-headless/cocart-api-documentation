### `cocart_product_quantity_editable`

Plugin: <Badge color="red">Basic</Badge>

Filter allows you to control whether a cart item's quantity can be changed by the customer. When `false`, the quantity is locked and the `editable` field in the cart response reflects this.

<Note>Made available since v5.0.0</Note>

**Parameters**

<ParamField query="editable" type="boolean">
  Whether the quantity can be changed. Default: `true`.
</ParamField>

<ParamField query="product" type="WC_Product">
  The product object.
</ParamField>

**Usage**
```php
add_filter( 'cocart_product_quantity_editable', function( $editable, $product ) {
    // Lock quantity for a specific product
    if ( $product->get_id() === 123 ) {
        return false;
    }
    return $editable;
}, 10, 2 );
```

### `cocart_quantity_multiple_of`

Plugin: <Badge color="red">Basic</Badge>

Filter allows you to control the quantity step (multiple of) for a product. This determines the increment value when customers adjust quantities.

<Note>Made available since v5.0.0</Note>

**Parameters**

<ParamField query="multiple_of" type="integer">
  The quantity step value. Default: `1`.
</ParamField>

<ParamField query="product" type="WC_Product">
  The product object.
</ParamField>

**Usage**
```php
add_filter( 'cocart_quantity_multiple_of', function( $multiple_of, $product ) {
    // Sell in packs of 6
    if ( $product->get_category_ids() && in_array( 42, $product->get_category_ids() ) ) {
        return 6;
    }
    return $multiple_of;
}, 10, 2 );
```
