### `cocart_rest_v1_product_schema`

Plugin: <Badge color="red">Basic</Badge>

Filter allows you to modify the product schema for API v1 responses. Use this to add custom fields or adjust the schema for your storefront needs.

<Note>Made available since v5.0.0</Note>

**Parameters**

<ParamField query="schema" type="array">
  The product schema properties.
</ParamField>

**Usage**
```php
add_filter( 'cocart_rest_v1_product_schema', function( $schema ) {
    $schema['custom_field'] = array(
        'description' => 'My custom field',
        'type'        => 'string',
        'context'     => array( 'view' ),
    );
    return $schema;
} );
```

<Note>
This replaces the deprecated `cocart_{$object_type}_schema` filter. See the [breaking changes guide](/breaking-changes/basic-v5) for details.
</Note>
