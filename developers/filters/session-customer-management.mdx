### `cocart_load_cart_from_session`

Plugin: <Badge color="red">Basic</Badge>

Filter allows you to decide if the cart should load user meta when initialized. Useful for controlling session behavior on specific pages or conditions.

<Note>Made available since v5.0.0</Note>

**Parameters**

<ParamField query="load_cart" type="boolean">
  Whether to load the cart from session. Default: `true`.
</ParamField>

**Usage**
```php
add_filter( 'cocart_load_cart_from_session', function( $load_cart ) {
    // Prevent cart from loading on specific conditions
    return $load_cart;
} );
```

### `cocart_load_cart_redirect_home`

Plugin: <Badge color="red">Basic</Badge>

Filter allows you to change where to redirect the customer if [loading the cart from session](/load-cart) fails.

<Note>Made available since v5.0.0</Note>

**Parameters**

<ParamField query="redirect_url" type="string">
  The URL to redirect to on failure. Default: home URL.
</ParamField>

**Usage**
```php
add_filter( 'cocart_load_cart_redirect_home', function( $redirect_url ) {
    // Redirect to a custom error page
    return home_url( '/cart-error/' );
} );
```
