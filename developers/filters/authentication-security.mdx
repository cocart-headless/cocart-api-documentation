### `cocart_login_permission_callback`

Plugin: <Badge color="blue">Community</Badge>

Filter allows you to modify the permission result after basic authentication. This is the primary hook for adding custom validation, external system checks, or role-based access control.

<Note>Made available since v4.8.0</Note>

**Parameters**

<ParamField query="permission" type="boolean|WP_Error">
  Current permission status (`true` after basic auth succeeds).
</ParamField>

<ParamField query="current_user" type="WP_User">
  The authenticated user object.
</ParamField>

<ParamField query="request" type="WP_REST_Request">
  The current REST API request.
</ParamField>

<ParamField query="endpoint" type="string">
  The endpoint being accessed (e.g. `'login'`).
</ParamField>

**Usage**
```php
add_filter( 'cocart_login_permission_callback', function( $permission, $current_user, $request, $endpoint ) {
    // Return true to allow, or WP_Error to deny
    if ( ! user_can( $current_user, 'access_api' ) ) {
        return new WP_Error(
            'cocart_insufficient_permissions',
            'User lacks required permissions for API access',
            array( 'status' => 403 )
        );
    }

    return $permission;
}, 10, 4 );
```

<Tip>
See the [Authentication Injection tutorial](/tutorials/authentication-injection) for advanced examples including SSO, role-based access, and geolocation checks.
</Tip>

[Search `cocart_login_permission_callback` in repository](https://github.com/co-cart/co-cart/search?q=cocart_login_permission_callback&type=code)

### `cocart_trusted_proxies`

Plugin: <Badge color="blue">Community</Badge>

Filter allows you to define trusted proxy IP addresses for accurate client IP detection. Essential if you're running CoCart behind a reverse proxy, load balancer, or CDN.

<Note>Made available since v4.8.0</Note>

**Parameters**

<ParamField query="trusted_proxies" type="array">
  Array of trusted proxy IP addresses. Empty by default.
</ParamField>

**Usage**
```php
add_filter( 'cocart_trusted_proxies', function( $proxies ) {
    return array(
        '10.0.0.1',
        '10.0.0.2',
        '192.168.1.0/24', // CIDR notation supported
    );
} );
```

[Search `cocart_trusted_proxies` in repository](https://github.com/co-cart/co-cart/search?q=cocart_trusted_proxies&type=code)

### `cocart_allowed_http_origins`

Plugin: <Badge color="red">Starter</Badge>

Filter allows you to change the origin types allowed for HTTP requests. Use this to extend or restrict which origins can access the API beyond the default CORS configuration.

<Note>Made available since v5.0.0</Note>

**Parameters**

<ParamField query="origins" type="array">
  Array of allowed origin types.
</ParamField>

**Usage**
```php
add_filter( 'cocart_allowed_http_origins', function( $origins ) {
    $origins[] = 'https://my-storefront.com';
    $origins[] = 'https://staging.my-storefront.com';
    return $origins;
} );
```

### `cocart_api_rate_limit_options`

Plugin: <Badge color="purple">Plus</Badge>

Filters the rate limiting configuration options for the REST API. Adjust limits and time windows to suit your traffic patterns.

<Note>Made available since v1.0.0 of CoCart Plus</Note>

**Parameters**

<ParamField query="options" type="array">
  Rate limit options array containing `enabled` (bool), `limit` (int), and `seconds` (int).
</ParamField>

**Usage**
```php
add_filter( 'cocart_api_rate_limit_options', function( $options ) {
    $options['limit']   = 100; // Allow 100 requests
    $options['seconds'] = 60;  // Per 60 seconds
    return $options;
} );
```
