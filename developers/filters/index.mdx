## Plugin Key Index

Badges identify which plugin each filter is available in:

| Plugin    | Badge |
|-----------|-------|
| Community | <Badge color="blue">Community</Badge> |
| Basic     | <Badge color="red">Basic</Badge> |
| Plus      | <Badge color="purple">Plus</Badge> |

<Info>
  Filters in the Community plugin are also available in Basic unless stated otherwise. Filters in Basic are not available in Community.
</Info>

<Tip>
  Looking for JWT Authentication filters? See [JWT filters](/developers/jwt/filters).
</Tip>
