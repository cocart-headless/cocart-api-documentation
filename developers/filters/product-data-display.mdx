### `cocart_prepare_product_object_v2`

Plugin: <Badge color="blue">Community</Badge>

Filter the data for a v2 product response. Fires after every v2 product response is assembled, for both the collection (`GET /cocart/v2/products`) and the single-product endpoint (`GET /cocart/v2/products/{id}`). Use this to append custom fields to `$response->data`.

<Info>
  Made available since v2.1.0
</Info>

**Parameters**

<ParamField query="response" type="WP_REST_Response">
  The response object. Append custom fields to `$response->data`.
</ParamField>

<ParamField query="product" type="WC_Product">
  The product object. Use WC_Product methods to read product data.
</ParamField>

<ParamField query="request" type="WP_REST_Request">
  The request object.
</ParamField>

**Usage**
```php
add_filter( 'cocart_prepare_product_object_v2', function( $response, $product, $request ) {
    $response->data['my_field'] = 'my value';
    return $response;
}, 10, 3 );
```

[Search `cocart_prepare_product_object_v2` in repository](https://github.com/co-cart/co-cart/search?q=cocart_prepare_product_object_v2&type=code)

### `cocart_products_allowed_meta_keys`

Plugin: <Badge color="red">Starter</Badge>

Filter allows you to specify which product meta keys are allowed in API responses. In CoCart Starter, product meta is no longer returned by default to prevent PII exposure — you must whitelist specific keys using this filter.

<Note>Made available since v5.0.0</Note>

**Parameters**

<ParamField query="allowed_keys" type="array">
  Array of allowed meta key names. Empty by default.
</ParamField>

<ParamField query="product" type="WC_Product">
  The product object.
</ParamField>

**Usage**
```php
add_filter( 'cocart_products_allowed_meta_keys', function( $allowed_keys, $product ) {
    // Allow specific meta keys in the response
    return array( '_custom_field', '_brand', '_material' );
}, 10, 2 );
```

<Warning>
  This replaces the `cocart_products_ignore_private_meta_keys` filter from the Community edition, which is [no longer used in Starter](/breaking-changes/starter-v5).
</Warning>
