### `cocart_cart_updated`

Plugin: <Badge color="blue">Community</Badge>

<Warning>**Deprecated:** v4.1.0 — Replaced with `cocart_update_cart_before_totals` and `cocart_update_cart_after_totals` hooks for more precise control over when your code runs relative to cart total calculations.</Warning>

Fires after the cart has updated via a callback.

<Note>Made available since v3.1.0</Note>

**Usage**
```php
add_action( 'cocart_cart_updated', function() {
    // Your code here
});
```
