### `cocart_init`

Plugin: <Badge color="blue">Community</Badge>

Fires once the CoCart plugin has finished loading.

<Note>Made available since v3.0.0</Note>

**Usage**
```php
add_action( 'cocart_init', function() {
    // Your code here
});
```

### `cocart_register_settings_providers`

Plugin: <Badge color="red">Starter</Badge>

Fires on `admin_init` after the built-in settings providers are registered. Use this hook to register your add-on as a settings provider via `CoCart_Settings_Registry`.

<Note>Made available since v5.0.0</Note>

**Usage**
```php
add_action( 'cocart_register_settings_providers', function() {
    CoCart_Settings_Registry::register( new My_Plugin_Settings_Provider() );
} );
```
