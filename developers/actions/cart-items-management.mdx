### `cocart_item_added_updated_in_cart`

Plugin: <Badge color="blue">Community</Badge>

Fires if item was added again to the cart but updated the quantity.

<Note>Made available since v2.1.0</Note>

**Parameters**

  Item key of the item added again.
</ParamField>

</ParamField>

<ParamField path="new_quantity" type="int">
  New quantity of the item.
</ParamField>

**Usage**

### `cocart_item_updated`

Plugin: <Badge color="red">Basic</Badge>

Fires once an item has been updated in the cart. Use this to trigger side effects like analytics events, inventory checks, or webhook notifications when cart items change.

<Note>Made available since v5.0.0</Note>

**Parameters**

<ParamField path="item_key" type="string">
  The item key of the updated item.
</ParamField>

<ParamField path="request" type="WP_REST_Request">
  The current REST API request.
</ParamField>

**Usage**
```php
add_action( 'cocart_item_updated', function( $item_key, $request ) {
    // Trigger analytics event when cart item is updated
    do_action( 'my_analytics_cart_item_updated', $item_key );
}, 10, 2 );
```
