### `cocart_cart_created`

Plugin: <Badge color="red">Basic</Badge>

Fires once a new cart is created. Use this to trigger welcome flows, initialize tracking, or set up cart-level defaults for new sessions.

<Note>Made available since v5.0.0</Note>

**Parameters**

<ParamField path="cart_key" type="string">
  The cart key of the newly created cart.
</ParamField>

**Usage**
```php
add_action( 'cocart_cart_created', function( $cart_key ) {
    // Log new cart creation
    error_log( sprintf( 'New cart created: %s', $cart_key ) );
}, 10 );
```
