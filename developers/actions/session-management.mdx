### `cocart_after_session_saved_data`

Plugin: <Badge color="blue">Community</Badge>

Fires after session data is saved.

<Note>Made available since v4.2.0</Note>

**Parameters**

<ParamField path="customer_id" type="int">
  Customer ID.
</ParamField>

<ParamField path="data" type="array">
  Cart data.
</ParamField>

<ParamField path="cart_expiration" type="int">
  Cart expiration.
</ParamField>

<ParamField path="cart_source" type="string">
  Cart source.
</ParamField>

**Usage**
```php
add_action( 'cocart_after_session_saved_data', function() {
    // Your code here
}, 10 );
```

### `cocart_set_requested_cart`

Plugin: <Badge color="red">Starter</Badge>

Fires before the session is finally set for the requested cart. Use this to perform actions or validations just before a specific cart session is loaded.

<Note>Made available since v5.0.0</Note>

**Parameters**

<ParamField path="cart_key" type="string">
  The cart key being requested.
</ParamField>

<ParamField path="request" type="WP_REST_Request">
  The current REST API request.
</ParamField>

**Usage**
```php
add_action( 'cocart_set_requested_cart', function( $cart_key, $request ) {
    // Log which cart is being loaded
    error_log( sprintf( 'Loading cart session: %s', $cart_key ) );
}, 10, 2 );
```
